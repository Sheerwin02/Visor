# visor-app

The VISOR web client: Bevy 0.20.1 (WebGL2) compiled to wasm with Trunk, HTML interface in Leptos 0.8. It reads only `../assets/`.

## Build

```
trunk serve                                  # everyday build (wasm-dev profile), http://127.0.0.1:8080
trunk build --cargo-profile wasm-release     # public build (small, fat LTO, wasm-opt)
cargo test -p visor-app                      # native tests (run from the repo root)
```

## Source layout (`src/`)

- `main.rs` app setup and bundle loading; `text.rs` typed words from `text/en.json` (generated by `build.rs`, placeholders checked at compile time).
- `scene/` the 3D world: terrain and photo, cameras (orbit, map, Walk), keys (`controls.rs`), map layers, the terrain overlay
  shader (`trust.rs` + `overlay.wesl`), Walk sky and light (`walkscene.rs`, `sky.wesl`), astronauts and Curiosity, map
  selection (`select.rs`) and placed relay / working spots (`place.rs`).
- `plan/` planning: live re-planning in a Web Worker (`planner.rs`, `compute.rs`, crate `plan-worker`), sun and shadows,
  day / twilight / night (`daylight.rs`), EVA simulation (`sim.rs`, `simrun.rs`), crew margins, relay, share link and exports.
- `ui/` the HTML interface: models published through `UiBridge` and the Leptos components in `ui/views/` (mission bar, layer
  rail, inspector tabs, stop card, drill-in card, timeline, Walk HUD).

## Controls

Plan: click a pin, stop, chemistry target or leg; drag to pan / rotate; wheel to zoom; drag a station pin to move it.
Walk (Tab or M): W A S D, mouse drag to look, click the ground to walk there, N faces the next stop, C first / third person,
right mouse for binoculars, H hides the HUD. `?mode=walk` opens in Walk.

## Notes

- WebGL2 only (Bevy's WebGPU build fails on browsers without WebGPU). One shadow cascade (WebGL2 limit).
- Shaders are warmed up during loading; the first switch to Walk still costs about 0.1 s (browser shader compile).
- Every number on screen comes from the bundle or the live plan; assumptions are labelled where they appear.
